# Dons Banyak Uang Studio

Buatkan website toko online produk digital dengan brand:

"DONS BANYAK UANG"

Gunakan bahasa Indonesia untuk seluruh website.

PENTING:

Website ini HANYA memiliki 3 halaman utama:

1. Home

2. Produk

3. Detail Produk

Jangan membuat halaman tambahan seperti:

- Login

- Register

- Dashboard

- Keranjang

- Checkout

- Payment

- Admin

- Blog

Fokus pada UI/UX yang sederhana, modern, bersih, dan profesional.
